# Лабораторная работа 4. Собственные контейнеры: списки и бинарное дерево

## Что делает программа
Реализованы собственные динамические структуры данных на C++ (без использования STL-контейнеров):

- `MyForwardList` — односвязный список (`int32_t`): добавление в конец, удаление первого чётного элемента, очистка, вывод;
- `MyList` — двусвязный список (`double`): добавление в конец, вставка нового элемента после элемента с заданным значением, очистка, вывод;
- `BinaryTree` — идеально сбалансированное бинарное дерево символов: построение из массива, подсчёт количества листьев, преобразование в дерево поиска (перезапись узлов при in-order обходе отсортированным массивом).

`Main.cpp` демонстрирует все операции по шагам: создание списков, обработка, очистка, построение дерева и его превращение в дерево поиска.

## Файлы
- `MyForwardList.h`, `MyForwardList.cpp` — односвязный список.
- `MyList.h`, `MyList.cpp` — двусвязный список.
- `BinaryTree.h`, `BinaryTree.cpp` — бинарное дерево.
- `Main.cpp` — демонстрационная программа.

## Сборка и запуск
Консольный проект C++: скомпилировать `Main.cpp` вместе с `.cpp` файлами контейнеров.
