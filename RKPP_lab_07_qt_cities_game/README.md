# Лабораторная работа 7. Игра «Города» на Qt

## Что делает программа
Графическое приложение на **Qt** (Qt Widgets) — игра «Города»:

- игроки по очереди вводят названия городов в текстовое поле;
- следующий город должен начинаться с последней буквы предыдущего (буквы **ь, ъ, ы** пропускаются — берётся предыдущая буква);
- повторно называть уже использованный город нельзя;
- ошибки и повторы показываются через `QMessageBox`;
- история ходов выводится в список, подсказка «на какую букву нужен следующий город» — в подпись на форме;
- сигнально-слотовое соединение (`connect`) связывает кнопку с обработчиком хода.

Проект создан в Qt Creator (CMake), базовый шаблон диалога (`dialog.cpp`) — стартовая заготовка, основная логика — в `citygamedialog.cpp`.

## Файлы
- `main.cpp` — точка входа.
- `citygamedialog.h/.cpp/.ui` — диалог игры «Города».
- `dialog.h/.cpp/.ui` — базовый шаблон диалога.
- `CMakeLists.txt` — файл сборки CMake.

## Сборка и запуск
Открыть папку проекта в Qt Creator и запустить (CMake, Qt Widgets). Либо вручную: `cmake -B build` и `cmake --build build`.
