# Лабораторная работа 1. Шаблонный класс DynArray и разбор чисел из строки

## Что делает программа
Две задачи на C++:

1. `Main.cpp` + `DynArray.h`/`DynArray.cpp` — шаблонный класс динамического массива `DynArray<T>` на основе `std::vector`:
   - конструктор с заданным размером, деструктор;
   - конструктор копирования и оператор присваивания копированием;
   - конструктор перемещения и оператор присваивания перемещением (`noexcept`);
   - инициализация элементов и вывод массива.
   В `Main.cpp` демонстрируются все конструкторы и операторы для типов `int`, `double`, `char`.

2. `lab_01_1.cpp` — программа читает строку и выводит все содержащиеся в ней числа, каждое с новой строки.

## Файлы
- `DynArray.h`, `DynArray.cpp` — шаблонный класс динамического массива.
- `Main.cpp` — демонстрация DynArray.
- `lab_01_1.cpp` — выделение чисел из строки.

## Сборка и запуск
Компилировать в Visual Studio (C++). Каждая задача — отдельная точка входа `main`.
