# Лабораторная работа 3. Расписание автобусов (множественное наследование)

## Что делает программа
Консольное приложение на C++ (Visual Studio) для учёта расписания автобусов:

- класс `Bus` построен через **множественное наследование** от `BusBase` (номер рейса, пункт назначения, тип автобуса) и `TimeInfo` (время отправления/прибытия, класс `Time` с парсингом `HH:MM`);
- пользователь вводит данные автобусов с клавиатуры (пустой номер рейса завершает ввод), все поля проверяются с выбрасыванием исключений;
- программа ищет все рейсы до заданного пункта назначения с временем прибытия не позже заданного;
- найденные рейсы сортируются по времени прибытия и записываются в файл `buses_output.txt`.

## Файлы
- `Main.cpp` — ввод данных, поиск и запись результата в файл.
- `Bus.h`, `Bus.cpp` — класс автобуса (множественное наследование).
- `BusBase.h`, `BusBase.cpp` — базовый класс автобуса.
- `Time.h`, `Time.cpp`, `TimeInfo.h`, `TimeInfo.cpp` — работа со временем.
- `class3.sln`, `class3.vcxproj` — проект Visual Studio.
- `buses_output.txt` — пример файла с результатом.

## Сборка и запуск
Открыть `class3.sln` в Visual Studio и собрать (консольное приложение).
