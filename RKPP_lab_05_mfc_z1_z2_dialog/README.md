# Лабораторная работа 5. MFC-приложение: вычисление z1 и z2 по формуле

## Что делает программа
Диалоговое приложение на C++ с использованием **MFC** (Visual Studio):

- класс `X` вычисляет два выражения по параметру `m`:
  - `z1 = √((3m+2)² − 24m) / (3√m − 2/√m)`
  - `z2 = −√m`
  и показывает, что результаты совпадают (проверка тождества);
- ошибки обрабатываются сообщениями: `m` должно быть строго больше 0, знаменатель не должен обращаться в ноль;
- диалоговое окно принимает значение `m`, методы класса вызываются по кнопкам, результаты выводятся через `AfxMessageBox`.

Открыть `lab_05_Gorbatovsky.sln` в Visual Studio (нужен компонент MFC) и собрать конфигурацию x64/Debug.
