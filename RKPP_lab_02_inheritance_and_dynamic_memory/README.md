# Лабораторная работа 2. Наследование классов и динамическая память

## Что делает программа
Две задачи на C++:

1. `lab_02_1` — иерархия классов: базовый класс `X` (поля `x1`, `x2`, виртуальные методы `show` и `set`) и производный класс `Y` (дополнительное поле `y`, метод `Run` — сумма квадратов переменных). Демонстрируются виртуальные функции, перекрытие методов и работа с объектами через указатель на базовый класс.

2. `lab_02_2` — работа с динамической памятью:
   - `1.cpp` — ввод двух массивов по 5 элементов (`new`), прибавление к каждому элементу массива его минимального элемента, вывод и освобождение памяти (`delete[]`);
   - `2.cpp` — ввод квадратной матрицы `n x n` (динамический массив указателей), подсчёт количества и суммы отрицательных элементов с проверкой переполнения.

## Файлы
- `lab_02_1/class2.h`, `class2.cpp`, `Main.cpp`, `class_2/` — наследование и виртуальные методы.
- `lab_02_2/1.cpp` — массивы в динамической памяти.
- `lab_02_2/2.cpp` — матрица и отрицательные элементы.
- `lab_02_1/lab_02_1.rar` — архив с исходниками первой задачи.

## Сборка и запуск
Компилировать в Visual Studio (C++). Каждый вариант — отдельный проект с собственной точкой входа.
