# Лабораторная работа 6. Алгоритмы обработки vector: удаление, вставка, сдвиг, поиск, сортировка

## Что делает программа
Консольная программа на C++ демонстрирует работу с контейнером `std::vector` и алгоритмами:

1. генерация массива из `n` случайных чисел;
2. удаление элемента по индексу (`erase`);
3. вставка `N` новых случайных элементов в позицию `K` (`insert`);
4. циклический сдвиг влево на `M` позиций (`rotate`);
5. линейный поиск элемента с подсчётом числа сравнений (`find_if`);
6. сортировка вставками (через `rotate` и `upper_bound`);
7. бинарный поиск по отсортированному массиву с подсчётом числа сравнений (`lower_bound`).

После каждого шага массив выводится на экран; для поиска выводится позиция элемента и число выполненных сравнений.
